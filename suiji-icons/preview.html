岁记 · 卡通图标预览Baby Growth Log · Icon Set

基于 PRD v1.2（云端轻量版） 的快速记录场景与 原型 v0.3 暖粉橙设计系统，为 8 个记录类别各设计两组成图：
小熊组（圆胖奶棕幼熊）与 小鸭组（圆黄小鸭），扁平 kawaii 风格 · 1920×1920 · 圆角徽章构图，类别底色与产品类别色一一对应。

使用说明

  • 规格：1920×1920 方形 JPG；主体居中于圆角徽章内，底色为类别浅色底（tint），无需抠图即可整卡使用。
  • 适用场景：快速记录面板磁贴（M1）、类别筛选标签、引导页 / 空状态插画、里程碑纪念卡片（M11）、家长端常用类别设置（M5）。
  • 两组定位：小熊组偏温暖亲和（默认推荐），小鸭组偏活泼明快；可按多宝宝（M9）为不同宝宝分配形象，也可用于主题皮肤切换。
  • 目录：suiji-icons/bear/01~08、suiji-icons/duck/01~08，文件名与类别英文键一致（feeding / sleep / milestone / photo / measure / poop / temp / med）。
  • 落地建议：小尺寸 UI（<96px）建议按本组形象重新矢量化描边版，当前位图更适合磁贴、插画与卡片等大尺寸场景。
