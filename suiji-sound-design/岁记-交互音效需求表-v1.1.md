## 一、v1.0 回访结论（为什么要改）

试听 v1.0 后产品侧反馈三点：**声音偏小、不够好听、点击类音效太少**。对照 `synth/manifest.json` 实测值，原因定位如下：

| 问题 | 根因（v1.0 实测） | v1.1 调整方向 |
| --- | --- | --- |
| 声音小 | 为同时满足「峰值 ≤ -3 dBFS」与「全程无限幅器」，用峰均比反推统一基准，绝对电平整体压低 1–4 LU：主基准 S-03 仅 **-19.6 LUFS**，多数交互音 **-24.6 ~ -28.6 LUFS**，成就音 **-20.6 LUFS** | 峰值上限放宽到 **-0.5 dBFS**，引入轻度 tanh 软饱和兜底；主基准上提到约 **-16 LUFS**，交互音 -18 ~ -22 LUFS，成就音 -13 ~ -16 LUFS |
| 不好听 / 发闷 | 3.5 kHz 以上做了 **-12 dB** 搁架，成品高频占比几乎全为 0.00%，卡林巴的木质光泽被削掉；泛音列只有 4 层，音色偏薄 | 搁架收到 **-7 dB**；泛音列加厚到 5 层并补一层低频共鸣；音头拨片噪声更柔；成就音尾部保留轻混响空间感 |
| 点击音少 | S 组只覆盖 FAB 展开、类型选中、保存、拦截、失败、快门、危险确认、恢复、切宝宝、开关 10 个场景；主按钮、列表项、返回、弹窗开合、标签选中、收藏、步进、缩略图、Toast、复制等基础交互均无声 | 新增 **14 条**基础交互音（S-12 ~ S-26），覆盖通用点击体系；高频次的 Tab 切换 / 下拉刷新 / 搜索仍按 v1.0 结论不做（防骚扰） |
| 里程碑不够"庆祝" | E-01 只有卡林巴琶音上行，情绪克制，但产品希望里程碑能有**温和的欢呼 / 喝彩**感 | E-01 五条变体在琶音后半段叠加一层**温和人声喝彩质感**（分解和弦元音群 + 轻气声合唱），不做尖锐"耶"、不做铃铛礼花；保留 5 变体随机 |

> 红线不变：夜间 / 医疗场景（体温 ≥38℃、百分位 <P3 等）仍不得出现警示音；S-03 仍须等服务端确认再播；除成就 / 纪念场景外不得使用上行琶音等庆祝语汇。详见 §六。

## 二、全局参数规范

### 2.1 声学参数

| 参数 | v1.0 | v1.1 | 说明 |
| --- | --- | --- | --- |
| 采样率 / 位深 | 44.1 kHz / 16bit 单声道 | 不变 | 与系统 UI 音一致 |
| 交付格式 | ogg（Vorbis q5）+ wav 母版 | 不变；本轮试听先出 WAV，接 App 前转 ogg/mp3 | SoundPool 解码 ogg |
| 峰值响度 | ≤ -3.2 dBFS，无限幅 | **≤ -0.5 dBFS**，tanh 软饱和兜底 | 给瞬态留出余量的同时把绝对电平提上来 |
| 感知响度 | 以 S-03 为 0 dB 的相对阶梯 | 相对阶梯口径不变；**绝对目标整体 +3 ~ 4 LU**，见 §2.1.1 | 相对阶梯仍是主验收口径 |
| 起振 / 收尾 | 4 ms 淡入，45–120 ms 淡出 | 不变 | 防爆音 / 防硬截断 |
| 频段 | 主体 200–2500 Hz，3.5 kHz 以上 -12 dB | 3.5 kHz 以上 **-7 dB**；高频占比预算放宽到 **12%** | 保留木质光泽，同时守住低端机不刺耳 |
| 声道 | 单声道 | 不变 | 手机单扬声器 |
| 命名 | `suiji_<id>_<语义>[_变体].wav` | 不变 | 新条目延续 v1.0 编号段 |

#### 2.1.1 响度阶梯与绝对目标

相对阶梯仍以 **S-03（保存成功，触发频次最高）为 0 dB 基准**，按 K 加权 RMS 排布。v1.1 各档绝对目标（近似 LUFS，供试听对照，真机以相对阶梯为准）：

| 音量档 | 相对 S-03 | 目标 LUFS（v1.1） | 典型条目 |
| --- | --- | --- | --- |
| 成就欢呼 | +1.5 | ≈ -13.5 | E-01 里程碑 |
| 成就 / 郑重 | -0.5 ~ -2.0 | ≈ -15 ~ -16 | E-06 / E-07 / E-10 / E-11 |
| 中（主基准 / 快门） | 0.0 | ≈ -16.0 | S-03 / S-06 |
| 中低（主按钮 / 危险 / 计时开始） | -0.5 ~ -1.5 | ≈ -16.5 ~ -17.5 | S-08 / S-12 / T-01 |
| 低（常规交互） | -2.5 ~ -5.0 | ≈ -18.5 ~ -20.5 | S-01 / S-09 / S-14 ~ S-25 |
| 极低（轻触 / 点缀） | -6.5 ~ -9.0 | ≈ -21.5 ~ -24.0 | S-11 / S-26 / E-03 |

> 说明：短音效的峰均比（PLR）仍在 11–17 dB，-0.5 dBFS 上限下用轻度软饱和保护瞬态，不做硬削波；若真机试听仍偏轻，优先在 App 播放侧把通道音量提到 1.05–1.1 倍，而不是再次压素材峰值。

### 2.2 播放通道与开关优先级（沿用 v1.0，不变）

- S 组 → `USAGE_ASSISTANCE_SONIFICATION`（跟随系统触摸提示音开关）；
- T / E 组 → `USAGE_NOTIFICATION` + `CONTENT_TYPE_SONIFICATION`（可被勿扰接管）；
- 开关优先级：系统静音 → 系统 DND → 应用内夜间静默（默认 22:00–07:00）→ 应用内音效分档 → TalkBack 静音。

### 2.3 时序约束（沿用 v1.0）

交互音端到端 ≤50 ms；S-03 必须服务端确认后播；成就音 ≤2000 ms 且不阻塞跳转；同类音效 800 ms 内去重。

### 3.3 明确不做（沿用 v1.0 结论）

- **S-13（旧）Tab 切换 / 时光轴筛选 / 下拉刷新 / 搜索**：频次过高，只用转场动效，不加音；
- **监护人同意项勾选 / 撤回**：合规场景禁止奖励感音色；
- **媒体上传进度音**：角标进度环 + 完成静态标记；
- **连续连击 / 滚动翻页音**：不做。

## 六、保留的实现红线（与 v1.0 一致）

1. **S-03 必须等服务端确认再播**，不得在乐观更新时响；
2. 音效开关与振动开关**分开**；夜间静默时段优先于一切；
3. 体温 ≥38℃、百分位 <P3、晚于参考范围等场景**不得出现任何警示音 / 警报音 / 急促振动**，只有静态文案；
4. 除 E-01 / E-07 / E-10 / E-11 / E-12 外，任何音效不得含上行琶音、和声渐强等庆祝语汇；
5. TalkBack / 无障碍开启时全部静音，音效不得作为唯一信息通道。

## 八、风格候选版本（bubble / drop，待试听选定）

v1.1 卡林巴木质风试听后未采纳，另出两套全量候选；**清单、响度阶梯、红线全部沿用 v1.1**，仅替换音色层。

```
synth-styles/
├─ synthesize.py        参数化合成器（两套共用同一套定标 / 软压 / 度量链）
├─ manifest-bubble.json 软合成气泡风 46 条实测参数
├─ manifest-drop.json   水滴气泡风 46 条实测参数
├─ wav-bubble/          软合成气泡风母版 WAV
└─ wav-drop/            水滴气泡风母版 WAV
full-preview/
├─ build_full_preview.py 对比页生成脚本
└─ index.html             双风格切换试听页
```

- **bubble 软合成气泡风**：圆润正弦 + 二次泛音 + 低频共鸣，音头轻上滑，现代轻快；
- **drop 水滴气泡风**：频率下扫 + 快衰减 + 短气泡噪声头，短促水滴感，轻快可爱。

实测（两套一致口径）：相对阶梯偏差 ≤0.1 dB（容差 ±1 dB），峰值 ≤ -0.5 dBFS，时长 <2 s，3.5 kHz 以上高频占比 ≤2.1%；S-03 基准约 -15.6 LUFS，里程碑 E-01 约 -14.2 LUFS。

待试听选定一套（或确认混搭）后，再转码并接入 `sound.js`；未选定前 `synth-v11/` 卡林巴版本保留对照，不删除。
