产品设计文档 · PRD

AI 成长日记重设计

产品：岁记 App（家庭成长记录）  ·   版本：v1.0  ·   日期：2026-11-18  ·   状态：待评审

01背景与目标

AI 成长日记当前是一条真实可用的生成管线（事实提取 → 通义千问生成 → 输出守卫 → 模板兜底），但产品体验与市面头部产品（亲宝宝 AI 成长月报、Tinybeans 月度回顾、格志等引导式 AI 日记）相比存在明显差距。

观察到的现状问题具体表现对用户的后果
内容像报表素材只有统计事实（喂养 X 次、睡眠 X 段、体重百分位），生成结果以数字排比为主；模板兜底更是纯数字罗列读完记不住任何瞬间，不像"日记"而像数据周报
触发被动必须用户主动点「生成本周日记」大多数家庭根本不会想起来，功能等于不存在
没有记忆点无标题、无摘要；照片缩略图堆在文末与正文无关列表里每篇长一样，回看时无从挑起
丢掉了主观记忆心情原文、语音转写等最有情感浓度的内容被统计数字淹没；家长脑中的"当时小故事"没有任何入口进入日记AI 只能写出数据，写不出"那天的笑容"

目标（可观察的结果）

  • 生成的日记以叙事瞬间为主体：读者能从文中看到至少一个具体场景，而不是一串统计数字。
  • 家庭在不主动操作的情况下，每周都能收到一篇已生成的日记草稿并知道去核对。
  • 家长的主观记忆（快问回答、心情原文）能进入日记正文。
  • 每篇日记有一眼可辨的标题，照片与讲述它的段落在一起。

关键产品决策（已确认）

决策结论
叙述口吻家人手记（第三人称温柔记录，像妈妈写的日记）。理由：与「归档进成长档案」的产品定位一致，风格生命周期长；宝宝口吻不作为默认。
与成长档案的关系维持既有定位：AI 日记是档案的章节素材，档案是日记的聚合成品；月报作为两者之间的中间层。
合规底线全文保留「AI 生成」标识与「请核对」提示；禁词守卫（医学结论/营销化表述）不放松。

02范围

最小完整旅程（P0 核心）：家长打开 App →（自动或手动）生成上周日记 → 看到带标题的叙事草稿 → 核对/微调 → 归档进成长档案。

阶段内容主要改动面
P0叙事化生成：素材升级、Prompt 重写、AI 标题与摘要、模板兜底同步改写、守卫句式拦截后端生成管线
P1快问引导、图文混排、日记列表改版（标题卡片 + 详情页）后端接口 + 前端日记页
P2自动生成与推送、月报聚合触发生成 + 通知 + 档案章节

P0 单独上线即有意义（老入口 + 新内容质量）；P1 依赖 P0 的标题/摘要字段；P2 依赖 P0/P1 稳定后的生成成本数据。

03核心流程

青色为新增环节（快问引导），粉色为重做环节（叙事生成）。触发双通道见 FR-06；生成算法本体见 FR-01。

04功能需求

FR-01 叙事化生成

把"统计素材 → 报表文案"的生成改为"故事素材 → 叙事文案"。用户可见结果：一篇像家人写的、有具体瞬间的手记。

素材升级（发往模型的内容）

素材现状升级后
宝宝画像无新增 BABY_PROFILE：小名/昵称、月龄、性别。仅限小名与月龄，不含姓氏与家长姓名（隐私边界见「共享规则」）。
心情与语音只计入总条数新增 MOOD：本周文字心情原文、语音转写文本，单条截断 200 字，最多选 5 条情感浓度高的（含"第一次""最"等表达、被家长标星的）。
里程碑名称+日期保留，并标注"第一次"系列优先入选。
照护统计喂养/睡眠/便便次数与均值降权为辅助素材：仅保留 1 条汇总，供结尾"平稳的一周"式收束使用，禁止展开成排比句。
测量数值+百分位保留现状（数值与 P 值允许出现，属事实白名单）。
快问回答—见 FR-03，作为最高权重素材注入。

生成规则

  • 口吻：家人手记（第三人称），称呼用宝宝小名；语气温柔克制，像写给未来的孩子看。
  • 结构：3–6 段；第一段以本周最有画面感的事件开篇；中段讲 1–2 个具体瞬间（心情原文/里程碑/快问回答择优）；结尾一段收束（可用照护统计做"平稳"基调，一段带过）。
  • 段落规格：每段 40–120 字；每段携带来源引用（沿用现有 src 溯源机制）。
  • 禁止：报表式排比（"喂养 X 次、睡眠 X 段、便便 X 次"式连续出现 2 组及以上即判违规）；医学结论与评估（沿用现有禁词表）；营销化表述；事实之外的日期与数字。

守卫调整

  • 数字白名单的比对范围扩大到心情原文/转写文本（原文中的数字天然合法）。
  • 新增句式守卫：输出中「X 次 / X 段 / X 张 / X 条」连续出现 ≥2 组 → 判为报表式，触发重生成。
  • 禁词表、引用完整性检查保持不变；里程碑固有名称（第一次翻身/微笑）不误杀的现状保留。

模板兜底（无 LLM / 两次生成失败）

兜底文案同步从数字罗列改为叙事式句库：按素材类型（里程碑/心情/照片/统计）预置 3–5 套句式模板随机轮换，统计数字只允许出现在句子的状语位置而非主体。兜底零 LLM 可用的现状不变。

生成失败的兜底链路不变：LLM 失败重试 1 次 → 守卫拦截重试 1 次 → 模板兜底；model_version 继续记录实际生成方式，Prompt 版本号升级。

FR-02 AI 标题与摘要

每篇日记生成时同时产出标题与一句话摘要，作为列表与档案章节的「脸面」。

字段规则示例
标题 title≤12 字，从本周最大记忆点提炼，口语化；守卫禁词同样适用「会翻身了的一周」「第一次叫妈妈」
摘要 summary≤40 字一句话，概括本周基调，不出现统计数字「这周她终于自己翻过了身，全家鼓掌鼓了半天。」
  • 标题/摘要在草稿状态下随正文一起可编辑（编辑页新增两个输入位）。
  • 旧数据（升级前生成的日记）无标题：列表与档案回退显示日期区间，不做批量补生成。
  • 归档后标题成为成长档案中该章节的标题。

FR-03 快问引导

把家长脑中的主观记忆装进日记：生成前 1–2 个轻量问题，可跳过、不阻塞。

规则

  • 出题来源：根据本周素材自动出题 —— 有里程碑 → 问"新技能当时的小故事"；照片 ≥5 张 → 问"哪张照片背后有故事"；有心情记录 → 问"这周她情绪最特别的一次"；兜底题 → "这周最让你印象深的瞬间"。每次最多 2 题。
  • 入口：① 手动点「生成本周日记」→ 先弹快问面板（跳过即直接生成）；② 自动生成不等待快问（见 FR-06），生成后草稿详情顶部出现「补一个瞬间」入口，回答后可点「重新生成」把回答注入（同区间覆盖草稿，归档态不可重新生成）。
  • 输入：单题 ≤200 字，纯文本；空答案视为跳过该题。
  • 存储：快问回答随草稿保存，供重新生成复用；归档后随日记留存；导出成长档案时不包含快问问答原文。

FR-04 图文混排

照片跟着讲述它的段落走，不再堆在文末。

  • 段落可携带关联照片（引用记录的 photo 项）；生成时模型从素材中的照片事件里挑选与段落语义相关的，每段最多 2 张，全文最多 6 张。
  • 未被段落引用的照片保留在文末「更多照片」横向条（现状缩略图逻辑降级为此）。
  • 嵌图点击进全屏媒体预览（沿用现有预览组件）；视频不参与段内嵌图，仅出现在「更多照片」。
  • 用户在编辑页可对每段增删嵌图；归档后不可改。
  • 模板兜底文案不嵌图（兜底无语义匹配能力），照片全部落在「更多照片」。

规则

  • 列表卡片：封面图（首段嵌图或本周首张照片）+ 标题 + 摘要（≤2 行）+ 日期区间（次要信息）+ 状态标签 + 照片/视频数量条。点击卡片：草稿 → 编辑页；归档 → 详情预览（只读）。
  • 详情页：图文混排正文 + 每段来源引用（折叠可展开，沿用溯源机制）。草稿态顶部保留「归档」主操作与快问补答入口。
  • 本周态：顶部主按钮逻辑保留 —— 本周无草稿显示「生成本周日记」，有草稿高亮显示「本周草稿待核对」。

  • 兼容性：无标题的旧日记按现状展示（回退日期区间），列表两种卡式并存。

FR-06 自动生成与推送

家庭"零操作"也能每周收到日记草稿：周一首次打开 App 时自动生成上周日记并通知。

触发与去重

  • 触发时机：每周一，家庭任一成员当天首次打开 App 时触发检查（后端幂等，多人同天打开只生成一次）。
  • 覆盖区间：上周一至上周日（自然周）。
  • 素材门槛：上周记录 ≥3 条，或含里程碑/照片/心情任意一项；不足则不生成、不通知、无任何打扰。
  • 去重：同家庭 + 同宝宝 + 同区间已有草稿或已归档日记 → 跳过自动生成（手动生成已有覆盖逻辑不受影响）。
  • 开关：设置中提供「自动生成成长日记」开关，默认开启；关闭后只保留手动入口。

通知

  • 生成成功后通知家庭全部成员：「本周成长日记已生成，看看这周的小故事吧」，点击进入日记详情。
  • 通知走现有家庭通知通道，沿用消息中心现有过滤与角标逻辑；自动生成消息不带操作人，不做"本人操作过滤"。
  • 生成失败（LLM 异常且兜底也不可用等）静默处理：不弹错误、不发通知，次日打开时自动重试；手动生成功能不受影响。

FR-07 月报聚合

周记之上的中间层：每月自动聚合上月月报，作为成长档案导出的直接素材。

  • 触发：每月 1 日，家庭任一成员当天首次打开 App 时检查；上月自然月无素材则跳过（同 FR-06 门槛与静默规则）。
  • 素材：上月各周记的标题与摘要 + 当月里程碑/测量/照片概览，复用同一生成管线，时间范围改为自然月。
  • 展示：月报与周记同列在日记档案列表，卡片带「月报」标识；归档态与周记一致。
  • 与档案的关系：月报是成长档案「时间范围 + 模板」导出时的默认章节素材来源；导出不重复统计（有月报的月份直接取月报聚合结果）。
  • TBD：月报是否同时提供手动触发入口（当前设计为仅自动）。

05共享规则

状态机（沿用并收窄）

草稿──核对编辑──▶归档 ｜ 草稿 30 天未归档自动清理（现状保留）
  • 自动生成只产出草稿；归档后不可重新生成、不可编辑（现状规则不变）。
  • 「重新生成」（快问补答触发）仅对草稿生效：同区间覆盖旧草稿正文/标题/摘要/嵌图，快问回答保留，重生成计一次生成。
  • 手动「生成本周日记」在已有本周草稿时等价于打开编辑页（现状逻辑不变）。

文案与合规

  • 「AI 生成」标识胶囊与「内容由 AI 自动生成，请核对」提示全文保留；结尾段的来源引用固定标注「AI 结尾 · 请核对」类提示。
  • 面向用户的提示文案口语化（如"看看这周的小故事吧"），避免技术说明式表述；合规提示除外。
  • 守卫禁词表（医学结论/评估/营销化）在本设计中不放松，仅按 FR-01 扩增句式守卫。
