形象演绎 · 两个气质方向

均保留 bear / duck 双 IP 切换机制（与 suiji-icons 图标库一致）。两个方向都把形象从 v2 的「纸面绘本」拉进「手作玩具盒」，但材质语言相反：一个做体积（黏土），一个做拼贴（贴纸）。下方迷你屏随顶部控制台色系 / IP 实时联动。

方向 A · 黏土玩具

CLAY TOY — 把岁岁从纸里「捏」出来
  • 无描边，靠光影塑形：径向高光 + 底部压痕，吉祥物像一团捏出来的软陶
  • 按钮 / FAB 用「挤出式」双层阴影，按压整体下沉 4px —— 像按下一块软黏土
  • 卡片厚圆角（26px）+ 顶高光柔影，整体是玩具盒的哑光质感
  • 动效语言 = squash & stretch：保存成功 = 吉祥物压扁回弹 + 陶土色圆点彩带
  • 背景安静（哑光渐变 + 柔光斑），无漂浮元素，突出记录内容本身

色系方案 · 三套候选

全部弃用 v2 的蜂蜜橙 #F7A15C / 奶油黄 #F5B32C。每套均把「宝宝内容色」（暖侧：记录卡片、时间轴、类别色）与「家长操作色」（冷侧：按钮、开关、系统提示）分离，且主色不与性别绑定 —— 男孩女孩用同一套。对比度按 WCAG 2.1 计算：正文 ≥4.5:1（AA）、大字号 ≥3:1；装饰色不承载文字则单独标注。

交互指引（效果图内均可演示）

  • FAB → 点右下 + 唤起 P08 面板，磁贴带旋转逐个「弹出 / 贴上」
  • 磁贴 → 关闭面板并 push 进入 P09 录入（标题、图标、副标题随类型切换）
  • 保存 → 吉祥物跳跃 + 彩带庆祝 2.2s，自动关闭并在 P01 顶部插入新卡片（上浮动画）
  • 删除草稿 → 危险操作二次确认弹窗（PRD §4.5 页面级约定）
  • 状态页签 → 空 / 加载 / 错误 / 边界四态均有动物主题动效；「只读角色」隐藏 FAB 并显示顶部横幅
  • Tab 栏 → 图标 hop 跳跃 + 页面过渡；「成长」进 P13 曲线入场绘制
  • 吉祥物 / 卡片 → 点按有 wig 摆动与按压形变反馈；吉祥物自动眨眼
  • P30 → 大字号长辈态：主按钮 ≥96px 触控区、开关 58px、正文 18px+

动效规格 · 时长 / 缓动 / uniapp 性能

总原则：只动画 transform 与 opacity（合成层，不触发重排重绘）；阴影 / 圆角变化一律用「预写两套 class 瞬时切换」而非动画 box-shadow。uniapp 侧：H5 直接 CSS；小程序端注意 rpx 换算与 cover-view 限制；nvue/weex 用 binding.animation 或 animation 模块。

方向 B · 模切贴纸

✔ 60 枚全部直接复用，零重绘

现有 bear/ 与 duck/ 各 30 枚图标均为「粗描边 + 平涂」，与贴纸描线语言一致；白色刀切边、硬偏移影、微旋转全部由 CSS 叠加，无需动源文件。
